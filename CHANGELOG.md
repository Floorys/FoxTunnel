# История изменений (Changelog)

Все заметные изменения проекта **FoxTunnel** фиксируются в этом файле.
Формат версий основан на [Semantic Versioning](https://semver.org/lang/ru/).

---

## [0.2.0] — 2026-11-10 (`v0.2.0`)

### Маршрутизация GeoIP, Geosite (Geodata), CIDR и Rule-Sets (как в Happ)
- **Новые типы правил:** `geosite` (поддержка категорий и фильтров `@attr` / `@!attr`, например `youtube`, `category-ads-all`, `google@!cn`), `geoip` (`ru`, `private`, `cloudflare` и др.), `cidr` (IPv4/IPv6 подсети) и `ruleset` (пользовательские списки `.srs` / `.json`).
- **Свои базы локально и по HTTPS-ссылке:** во вкладке **«Маршрутизация»** добавлен раздел «Базы GeoIP, Geosite и Rule-Sets» для подключения `geoip.dat` / `geosite.dat` (или готовых `.srs` / `.json`) по URL либо с диска (путь к файлу или загрузка из браузера).
- **Явное обновление баз по кнопке:** добавлены кнопки **«Обновить GeoIP»**, **«Обновить Geodata»**, **«Обновить все базы»**, обновление отдельных Rule-Set и опция скачивания через активный VPN (`SOCKS5`), с HTTPS-редиректами и лимитом размера 64 МБ.
- **Компиляция для `sing-box 1.14.4`:** встроен чистый protobuf-парсер `.dat` без сторонних зависимостей; используемые категории извлекаются, компилируются через `sing-box rule-set compile` и кэшируются в `%LOCALAPPDATA%\FoxTunnel\geo\compiled\`.
- **Точный порядок правил и DNS `resolve`:** при наличии `cidr`, `geoip`, `geosite` или `ruleset` запросы после доменных правил передаются в ядро `sing-box` с расстановкой `action: "resolve"` перед IP-правилами.
- **Тесты и документация:** добавлены unit-тесты для `.dat`/`.srs`/`.json`, `routePolicy`, `geo_update` / `geo_upload` и проверка конфига через `sing-box check`; обновлены [README.md](README.md) и UI.

## [0.1.0] — 2026-11-10

### Базовый релиз FoxTunnel
- **WebExtension MV2 + Native Messaging Host (`native/host.py`):** локальный запуск `sing-box 1.14.4` через `127.0.0.1:<port>` (без TUN и без прав администратора), `WindowsJob` (`KILL_ON_JOB_CLOSE`), блокировка второго экземпляра (`host.lock`), безопасное удаление временных конфигов.
- **Протоколы и подписки:** импорт и валидация `vless://`, `vmess://`, `hysteria2://`, `trojan://`, `ss://`, `tuic://`, `anytls://`, `socks://`, `http://`; сохраняемые и обновляемые HTTPS-подписки с ручным/периодическим обновлением без потери ручных профилей.
- **Проверка доступности конфигов:** реальный сквозной HTTP/HTTPS-запрос через изолированный временный экземпляр `sing-box` с измерением задержки.
- **Безопасность и интерфейс:** fail-closed Kill Switch с баннером восстановления, WebRTC `disable_non_proxied_udp`, удалённый DNS / DoH (`detour -> proxy`), системная / тёмная / светлая тема, скрипт проверки `scripts/verify.py` и сборщик `scripts/build.py`.
